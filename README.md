# ReviewMate (RM)

모바일 우선으로 만든 소상공인을 위한 리뷰·고객·매장 개선 관리 서비스 ReviewMate의 초기 프로젝트입니다.

## 1. 포함 기능

- 반응형 모바일/PC 대시보드
- 리뷰 목록, 별점 필터, 답글 초안 생성 및 저장
- 고객 메모와 단골 쿠폰 발급 안내
- 리뷰 키워드 인사이트 및 개선 행동 제안 화면
- 개선 과제 등록/완료 처리
- AI 상담 비서 데모
- 인스타그램/스레드 콘텐츠 초안 생성, 복사, 캘린더 저장
- 매장 정보 설정 및 브라우저 데이터 저장
- Vercel Serverless Function을 통한 선택적 AI API 연결
- Supabase용 초기 데이터베이스 스키마

## 2. 디자인 원칙

- 그라데이션 없음
- 가구/인테리어/장식 사진 없음
- 아이보리, 화이트, 차콜의 단색 중심
- 넉넉한 여백과 절제된 선·카드
- 모바일 우선 반응형 레이아웃

## 3. 로컬 실행

Node.js가 설치되어 있어야 합니다.

```bash
npm install
npm install -g vercel
vercel dev
```

터미널에 표시되는 로컬 주소로 접속합니다. 정적 HTML만 빠르게 확인하려면 VS Code Live Server 등으로 `index.html`을 열어도 됩니다. 단, `/api/ai`는 Vercel 개발 서버에서 실행해야 합니다.

## 4. GitHub + Vercel 배포

1. ZIP 압축을 풉니다.
2. 폴더를 GitHub 새 저장소에 업로드합니다.
3. Vercel에서 **Add New → Project**를 선택합니다.
4. GitHub 저장소를 Import 합니다.
5. Framework Preset은 Other, Build Command는 비워두고 Output Directory는 기본값으로 둡니다.
6. Deploy를 누릅니다.

이 프로젝트는 빌드 단계가 없는 정적 HTML/CSS/JS와 Vercel Functions 구조입니다.

## 5. AI 기능 연결

1. `.env.example`을 참고해 로컬에서는 `.env.local` 파일을 만들고 `OPENAI_API_KEY`를 입력합니다.
2. Vercel 프로젝트의 Settings → Environment Variables에도 `OPENAI_API_KEY`를 등록합니다.
3. 재배포합니다.

API 키는 반드시 서버 환경변수로만 보관하세요. 브라우저 JavaScript에 키를 직접 입력하지 마세요.

키가 없거나 AI API 호출에 실패하면 리뷰 답글/상담/SNS 초안 기능은 데모용 로컬 문구로 대체됩니다. 따라서 API 미설정 상태에서도 화면 흐름을 시험할 수 있습니다.

## 6. 데이터 저장과 Supabase

현재 버전은 브라우저 `localStorage`에 데모 데이터를 저장합니다. 같은 브라우저에서는 새로고침 후에도 데이터가 유지되지만, 기기 간 동기화나 사용자별 계정 저장은 제공하지 않습니다.

`supabase/schema.sql`은 매장, 직원, 리뷰, 고객 메모, 개선 과제, SNS 초안의 초기 테이블 구조입니다. 실제 운영 전에 다음 작업이 필요합니다.

- Supabase 프로젝트 생성 및 Auth 로그인 구현
- 테이블별 RLS 정책과 매장 멤버 권한 정책 완성
- 프론트엔드 데이터 계층을 Supabase로 교체
- 개인정보 처리방침, 보유기간, 삭제 요청 절차 마련
- 백업 및 접근 로그 정책 수립

SQL에는 안전을 위해 소유자 정책의 시작점만 포함했습니다. 나머지 테이블에 대한 정책을 검증하기 전에는 클라이언트에서 테이블 접근을 열지 마세요.

## 7. 실제 외부 연동이 필요한 기능

이 ZIP은 실제 플랫폼 데이터 연동을 가장하지 않습니다. 아래 기능은 각 서비스의 공식 API, 사업자 권한, 심사 및 별도 개발이 필요합니다.

- 네이버 플레이스 및 배달앱 리뷰 자동 수집/답글 게시
- 카카오톡 알림 발송
- 실제 쿠폰 발급 및 고객 식별
- Instagram/Threads 계정 OAuth 인증, 게시 및 인사이트 조회
- 결제/정기 구독과 영수증 발급

SNS 화면의 콘텐츠 초안 작성과 캘린더 저장은 데모로 동작하지만, 실제 예약 게시 기능은 연결되어 있지 않습니다.

## 8. 운영 전 필수 점검

- 개인정보 및 고객 식별 정보의 적법한 수집 근거 확인
- 고객 데이터 최소 수집 및 자동 삭제 정책
- 리뷰 플랫폼별 API/약관/자동 답글 허용 범위 확인
- AI 생성 답글을 사람이 검토한 뒤 게시하도록 운영
- API 사용량 제한, 오류 로깅, rate limit 적용
- 실제 결제 전 구독 해지/환불/세금 관련 정책 검토
- 모바일 Safari/Chrome 및 데스크톱 브라우저 테스트

## 10. 현재 버전의 범위

이 프로젝트는 **배포 가능한 프론트엔드 데모 + 선택적 AI 서버 함수 + DB 초기 스키마**입니다. 완성된 상용 SaaS 백엔드(인증, 다중 사용자 데이터 동기화, 결제, 실제 리뷰/SNS API 연동)가 모두 구현된 것은 아닙니다. 실제 고객에게 유료 제공하기 전 위의 외부 연동과 보안 작업을 완료해야 합니다.
